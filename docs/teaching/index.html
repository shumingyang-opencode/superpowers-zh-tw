教學解說

教學中心是 Superpowers 的深度學習入口。技能頁是逐段對照的翻譯，這裡是策展式的深度解說——用中文把整套方法論講透。

建議的學習順序：方法論總覽（建立全貌）→ 工作流拆解（理解流程）→ 哲學四原則（理解背後的設計邏輯）→ SDD 深度探討（理解核心執行模式）→ 如何寫 Skill（進階：自己擴展系統）。

Worked Example（具體案例）

案例：新手的學習路徑

  1. 先看方法論總覽：理解 Superpowers 是一條管線
  2. 再看工作流拆解：理解七個階段各自做什麼
  3. 走學習路線：按順序學每個技能
  4. 遇到問題時回來查教學中心的深度解說
